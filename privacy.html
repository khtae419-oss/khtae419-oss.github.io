개인정보처리방침

IPO 공모주 알리미는 운영자 본인이 사용하는 로컬 일정 관리 프로그램입니다. 이 방침은 프로그램의 Google 데이터 처리와 소개 사이트에 적용됩니다.

1. 접근하는 Google 데이터와 목적

Google OAuth로 승인받은 calendar.app.created 권한을 사용하여 앱이 만든 보조 캘린더와 해당 일정에 접근합니다. 캘린더 식별자, 일정 식별자, 일정 제목·설명·날짜 등을 처리하며, 목적은 공모주 청약·환불·상장 일정 생성, 변경 반영 및 중복 방지입니다.

인증을 유지하기 위해 액세스 토큰과 갱신 토큰을 처리합니다. Google 계정 비밀번호는 프로그램이 수집하거나 저장하지 않습니다.

2. 저장 위치와 보관

인증 토큰과 캘린더 식별자는 사용자의 PC에 있는 사용자 홈의 .ipo-automation 폴더에 저장됩니다. 공개 공모 정보, 영상 정보, 추출 점수 및 실행 이력은 프로젝트의 로컬 SQLite 데이터베이스와 로그에 저장됩니다.

인증 정보는 Git 저장소에서 제외합니다. 프로젝트 폴더가 OneDrive 등 동기화 폴더에 있는 경우 데이터베이스와 로그는 사용자의 동기화 설정에 따라 동기화될 수 있습니다.

로컬 설정과 기록은 사용자가 삭제할 때까지 보관합니다. 생성된 Google Calendar 일정은 사용자가 해당 캘린더에서 삭제할 때까지 남습니다.

3. 데이터 전송과 공유

인증과 일정 동기화에 필요한 요청은 Google로 전송됩니다. 공개 공모 정보는 38커뮤니케이션, 공개 영상·자막은 YouTube, 공개 휴장일은 KRX에서 조회합니다. Google 토큰이나 캘린더 데이터는 이들 정보 출처에 전달하지 않습니다.

Google 사용자 데이터를 판매하거나 광고 목적으로 사용하지 않으며, 범용 AI·머신러닝 모델의 학습에 사용하지 않습니다. 사람에 의한 접근은 운영자 본인의 로컬 관리와 명시적으로 요청한 문제 해결에 한정됩니다.

Google API를 통해 받은 정보의 사용 및 전송은 Google API Services User Data Policy와 Limited Use 요구사항을 따릅니다.

4. 권한 철회와 삭제

Google 계정의 연결 관리에서 앱의 접근 권한을 철회할 수 있습니다. 사용을 중단하려면 Windows 예약 작업을 중지하고 로컬 인증 파일·데이터베이스·로그를 삭제할 수 있습니다. 권한 철회는 기존 Google Calendar 일정을 자동 삭제하지 않습니다.

5. 소개 사이트와 문의

소개 사이트는 정적 페이지이며 자체 분석 도구, 광고, 로그인 양식 또는 캘린더 데이터 수집 기능을 사용하지 않습니다. GitHub Pages로 게시할 경우 호스팅 제공자가 서비스 운영을 위해 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.
